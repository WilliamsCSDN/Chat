商户入驻通常需要提交以下几类资料(具体以所入驻平台/渠道的最新要求为准):

## 一、主体资质类(必备)
- **营业执照**副本彩色扫描件(在有效期内,经营范围覆盖拟入驻类目)
- **法定代表人身份证**正反面扫描件(在有效期内)
- 如为**个体工商户**:经营者身份证 + 营业执照
- 如为**分公司/子公司**:总公司授权书(加盖公章)
- **组织机构代码证 / 税务登记证**(三证合一后一般无需单独提交)

## 二、经营/结算类
- **对公银行账户**开户许可证或基本户信息(账户名、开户行、账号)
- 如使用**法人个人账户**结算:法人身份证 + 银行卡正反面
- **联系人信息**:姓名、手机号、邮箱、常用地址

## 三、店铺/品牌类
- **店铺名称、Logo、简介**
- **品牌授权书**(如销售非自有品牌商品)
- **商标注册证 / TM 受理通知书**(自有品牌需提供)
- 如为**代理商**:品牌方逐级授权链条

## 四、行业特殊资质(按类目提交)
不同经营类目需额外提供对应许可证,常见如:
- **食品/生鲜**:食品经营许可证、SC 生产许可证、进口食品报关单/检疫证
- **餐饮**:食品经营许可证、门店实景照片
- **医疗器械/药品**:医疗器械经营许可证、药品经营许可证、GSP 认证
- **化妆品**:进口化妆品备案凭证、特殊用途化妆品批件
- **图书音像**:出版物经营许可证
- **3C 电子**:3C 认证证书
- **保健食品**:保健食品批准证书(蓝帽子)
- **教育/培训**:办学许可证
- **金融/支付**:相关金融牌照

## 五、场所/门店类(线下商户)
- **门店门头照、内景照、收银台照**
- **场所租赁合同 / 产权证明**
- 门店定位(经纬度或详细地址)

## 六、协议与承诺
- 签署平台《商户入驻协议》《服务费率协议》
- 《平台规则承诺函》《真实性声明》
- 部分平台要求缴纳**保证金 / 技术服务费**

---

## 建议
1. **先确认入驻平台**(如淘宝/天猫/京东/抖音/美团/微信支付/支付宝等),各家清单和审核口径不同。
2. **确认经营类目**,行业许可证是审核卡点,建议提前办理。
3. 所有证件保证**清晰彩色、在有效期内、信息一致**(名称、地址、法人需与营业执照完全一致)。
4. 若需要,我可以针对某个**具体平台**(如天猫/抖音小店/微信支付)给你更详细的入驻资料清单和流程。
