您好，关于佣金结算周期，我需要先从内部知识库中为您核实具体规则，因为不同业务线/合作模式的结算周期可能不同（常见的有 T+1、周结、半月结、月结等）。

在为您查询之前，可以先麻烦您补充以下信息，方便我给出准确答复：

1. 您所在的业务或角色（例如：分销商、推广员、主播、商家等）；
2. 结算所对应的订单类型（普通订单、预售订单、跨境订单等）；
3. 是否有指定的合作合同或活动，如有请提供合同/活动编号。

一般情况下的通用规则大致如下（仅供参考，以最终查询到的官方规则为准）：

- 订单需在买家确认收货且过售后期后，才会进入可结算状态；
- 满足结算条件的佣金通常会在下一个结算日统一入账；
- 入账后可在“我的钱包 / 结算中心”中申请提现，提现到账时间视支付渠道而定（一般 1–3 个工作日）。

我这边会同步去知识库查询您对应场景下的准确结算周期，稍后把具体天数和到账规则一并回复给您。
